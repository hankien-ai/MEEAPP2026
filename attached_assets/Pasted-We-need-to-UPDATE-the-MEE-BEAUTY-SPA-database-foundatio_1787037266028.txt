==================================================
1. PAYROLL REQUIREMENTS
==================================================

Add a simple but extensible payroll system.

Each staff member must support a salary configuration.

Salary should support:

1. Monthly fixed salary
2. Daily salary
3. Hourly salary

Use a clear enum such as:

SALARY_MONTHLY
SALARY_DAILY
SALARY_HOURLY

Do not hard-code salary calculation into the staff table.

Create a separate salary configuration/history table so salary changes over time do not destroy historical payroll data.

Suggested table:

staff_salary_settings

Fields should include:
- id
- organization_id
- branch_id
- staff_id
- salary_type
- salary_amount
- effective_from
- effective_to nullable
- is_active
- created_at
- updated_at

A staff member can have multiple historical salary records, but only one active salary setting for a given period.

3. PAYROLL RECORD
==================================================

Create payroll_records.

Each record represents one employee's payroll for one payroll period.

Fields should include:

- id
- organization_id
- branch_id
- payroll_period_id
- staff_id

Salary calculation snapshot:

- base_salary
- attendance_salary
- overtime_amount
- commission_amount
- bonus_amount
- deduction_amount
- total_amount

Also store calculation information such as:

- worked_days
- worked_hours
- late_count
- leave_approved_count
- leave_unapproved_count

The payroll record must preserve the calculated values as a snapshot.

IMPORTANT:
If the employee's salary or commission configuration changes later, old payroll must NOT change.

4. PAYROLL COMMISSION
==================================================

Payroll must be able to include commissions already generated by:

- SALES commission
- PERFORMANCE commission

Do not duplicate commission calculation logic.

Use the existing staff_commissions table as the source.

Payroll should be able to aggregate approved commissions for the selected period.

If useful, create a payroll_record_commissions relation table:

- payroll_record_id
- staff_commission_id
- amount

This allows us to know exactly which commissions were included in each payroll.

Once payroll is approved/paid, the historical payroll amount must remain stable.
